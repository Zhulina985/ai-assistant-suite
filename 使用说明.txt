英语口语陪练 - Windows 使用说明
=====================================

【从 GitHub 克隆后，按顺序操作】

  1. setup-tools.bat        检测 Java / Python / 创建 .env
  2. 编辑 backend-java\.env  填写 MYSQL_PASSWORD（必填）
  3. init-db.bat            创建 MySQL 数据库
  4. start-backend-java.bat  启动后端（窗口1）
  5. start-frontend.bat      启动前端（窗口2）
  6. 浏览器打开 http://127.0.0.1:5173/login.html

【环境要求】

  - JDK 17 或更高版本
  - MySQL 8（服务需已启动）
  - Python 3（用于前端静态服务）
  - Maven 已内置，无需单独安装

【测试连接】

  test-connection.bat

【常见错误】

  Unknown database 'speaking_coach'
  -> 运行 init-db.bat

  MYSQL_PASSWORD 为空
  -> 编辑 backend-java\.env

  端口 8000 被占用
  -> 运行 kill-port-8000.bat

  未检测到 Python
  -> 安装 Python 3 并勾选 Add to PATH

【注意】

  - 使用 .bat 文件，在 CMD 或资源管理器中双击即可
  - .env 含密码和 API Key，不要提交到 Git
  - API Key 可选，不填也能游客体验
